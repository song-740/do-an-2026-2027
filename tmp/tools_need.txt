Sysmon (ưu tiên số 1)

Config: dùng Olaf Hartong sysmon-modular — bật đủ Event ID 1 (Process Create), 3 (Network), 7 (ImageLoad), 8 (CreateRemoteThread), 10 (ProcessAccess), 11 (File), 12/13/14 (Registry), 17/18 (Pipe), 19/20/21 (WMI subscription)
Lý do Event 19/20/21 cực kỳ quan trọng ở đây: sẽ ghi lại việc tạo WMI NotepadTrigger

PowerShell logging qua GPO/registry (trước khi stage2 disable):

HKLM\SOFTWARE\Policies\Microsoft\Windows\PowerShell\
  ScriptBlockLogging\EnableScriptBlockLogging = 1
  ModuleLogging\EnableModuleLogging = 1
  Transcription\EnableTranscripting = 1


Audit Process Creation + Command Line (Event 4688):

Secpol.msc → Advanced Audit Policy → Detailed Tracking → Process Creation: Success
Enable “Include command line in process creation events”

WEF Collector trên máy analysis:

wecutil qc trên collector
winrm quickconfig trên client
Subscription: forward Security, Sysmon, PowerShell/Operational, WMI-Activity
